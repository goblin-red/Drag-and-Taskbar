# GOBL(in) Drag для macOS

[English](README.md) · **Русский**

Двигайте, сворачивайте и переключайте окна жестами трекпада. Зажмите клавишу-модификатор — и окно под
курсором поедет за пальцем, за какое бы место вы его ни «взяли». Целиться в заголовок больше не нужно.
Одно из дополнительных приложений [GOBL(in)](https://goblin.red). Прототип для Windows
в работе и пока не опубликован.

- **Перетаскивание без заголовка** — три режима: окно едет за курсором, пока зажат модификатор; за жестом
  двумя пальцами по трекпаду; или за мышью при зажатых модификаторе и правой кнопке.
- **Свайпы** — с зажатым модификатором свайп двумя пальцами влево или вправо сворачивает или закрывает окно
  под курсором (что именно — решаете вы); вверх — разворачивает, вниз — возвращает размер и выводит из полного экрана.
- **Фокус за курсором** — окно под курсором становится активным по нажатию модификатора или движению мыши с ним.
- **Переключатель окон** — Option+Tab показывает все окна запущенных приложений, включая свёрнутые.
- **Изменение размера** — Control + свайп двумя пальцами (включается в настройках).
- **Shift** отменяет перетаскивание.
- **Живёт в строке меню** — без значка в Dock, по желанию запускается при входе, настройки меняются на лету.

## Что нужно

- macOS 13 Ventura или новее
- Command Line Tools (`xcode-select --install`): сборка идёт напрямую через `swiftc`

## Установка

Вставьте в Терминал:

```sh
curl -fsSL https://raw.githubusercontent.com/goblin-red/two-finger-drag-macos/main/install.sh | bash
```

Скрипт скачивает готовую сборку из [Releases](https://github.com/goblin-red/two-finger-drag-macos/releases/latest),
кладёт её в `/Applications/GOBL(in) Drag` и открывает. Сборка универсальная: работает и на Apple Silicon, и на Mac с Intel,
инструменты Xcode не нужны. Затем один раз выдайте разрешение, см. [Разрешение](#разрешение). Ваш `config.txt` при обновлении
сохраняется. Чтобы обновиться, выполните ту же команду ещё раз.

Скачали архив вручную? Приложение не заверено Apple, поэтому скачанную копию macOS блокирует.
Разблокируйте её один раз:

```sh
xattr -dr com.apple.quarantine "/путь/к/GOBL(in) Drag"
```

## Сборка из исходников

```sh
git clone https://github.com/goblin-red/two-finger-drag-macos.git
cd two-finger-drag-macos

./create-cert.sh        # один раз: локальный сертификат подписи, чтобы разрешение не слетало
./build.sh              # универсальная сборка: Apple Silicon + Intel (по умолчанию)
open "GOBL(in) Drag.app"
```

Режимы сборки:

| Команда | Что собирает |
| --- | --- |
| `./build.sh` | arm64 + x86_64 в одном файле, работает на любом Mac (по умолчанию) |
| `./build.sh arm` | arm64, только Apple Silicon |
| `./build.sh intel` | x86_64, только Mac на Intel |

## Разрешение

Приложению нужен **Универсальный доступ**: *Системные настройки → Конфиденциальность и безопасность →
Универсальный доступ* → включите `GOBL(in) Drag`. Без него macOS не даёт видеть жесты и двигать окна.
С сертификатом из `create-cert.sh` разрешение сохраняется между пересборками.

## Как пользоваться (модификатор по умолчанию — ⌥ Option)

| Действие | Что происходит |
| --- | --- |
| ⌥ + движение курсора | окно под курсором едет за ним |
| ⌥ + свайп двумя пальцами влево / вправо | свернуть (или закрыть) окно |
| ⌥ + свайп двумя пальцами вверх / вниз | развернуть / вернуть размер |
| ⌥ + Tab | переключатель со всеми окнами |
| Shift во время перетаскивания | отменить перетаскивание |
| Control + свайп двумя пальцами | изменить размер окна (включается в настройках) |

## Настройки

Значок в строке меню → **Настройки…**. Все параметры также хранятся в текстовом файле `config.txt` рядом
с приложением, с комментарием к каждой строке. При первом запуске он создаётся со значениями по умолчанию;
в `default-config.txt` хранится их копия.

Интерфейс на английском и русском: по умолчанию английский, язык меняется в **Настройки → Перетаскивание → Язык**
(в английском окне: **Settings → Drag → Language**).
